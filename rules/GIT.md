# Git

本文件是 diff、checkpoint、milestone 与提交粒度的单一事实来源。

## 开始与恢复

已有仓库先运行 `git status` 和 `git diff`，识别用户已有修改并保护无关工作。不要覆盖、回退或删除不属于当前任务的改动。

## Checkpoint

高风险修改前建立可恢复的安全 checkpoint；功能完成且关键验证 PASS 后，可建立一个表达完整意图的 checkpoint。只有 Git 仓库、改动属于当前任务且提交不会夹带用户无关内容时才提交。

不要为每个微小操作生成提交，也不要把无关变化塞入同一提交。提交信息短、清晰，描述实际变化。

## Milestone

大阶段完成并通过必要回归、工程自检和文档同步后建立 milestone commit。若因用户已有修改、缺少 Git 身份或其他原因不能安全提交，如实报告，不伪造完成状态。

## 安全边界

禁止未经用户明确要求使用会丢失工作的操作，例如硬重置或覆盖式检出。删除项目内部内容前确认目标、可恢复性和引用；项目外重要文件遵循 `rules/SAFETY.md`。
