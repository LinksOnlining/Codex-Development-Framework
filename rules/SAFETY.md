# Safety

本文件是高风险、不可逆、凭据、数据与系统操作的单一事实来源。

## Codex 可自主处理

在已确认需求和项目范围内，Codex可自主进行可逆的普通开发操作：读取与搜索、创建或修改项目文件、运行检查和构建、安装必要且低风险的开发依赖、修复错误、维护相关文档和执行安全的 Git 操作。

## 必须询问用户

- 关键需求不明确、互相冲突或会显著改变验收结果；
- 整体技术栈、核心架构、核心数据模型或安全策略的重大改变；
- 不可逆操作、重要数据删除、破坏性迁移或恢复能力不足；
- 修改或删除项目范围外的重要文件；
- 密码、API Key、凭据、账号登录或权限授权；
- 付款、购买服务、明显新增一次性或长期成本；
- 重大系统级修改，或影响其他项目和用户环境的操作；
- 引入重大第三方服务、显著供应链风险或新的敏感数据流。

提问时说明问题、原因、影响、可行选项和推荐方案；完成已授权的可逆准备工作后，再让用户决定真正的分叉点。

## 执行保护

- 破坏性操作前精确解析目标，确认其在授权范围内，并优先选择可恢复方式。
- 不输出、提交或写入真实密钥；示例只能使用明显的占位值。
- 修改 Schema、权限、安全或数据路径前建立备份 / checkpoint 与回滚方案，并按 L3 验证。
- 普通项目开发期间中央库 `D:\AI_Workspace\Projects\AI_Project_Template` 视为只读；只有用户明确要求维护中央规范时才可修改。
- 发现高风险问题时暂停相关路径，但继续完成不受影响且已授权的安全工作。
