\# Sample AI Project



This example demonstrates how a software project can use Codex Development Framework.



\## Purpose



This sample shows the recommended project documentation structure for AI-assisted software development.



\## Project Documents



\### AGENTS.md



Contains project-specific instructions for AI coding agents.



Defines:



\- Development rules

\- Project constraints

\- Workflow requirements





\### PROJECT\_BRIEF.md



Defines:



\- Project goals

\- Requirements

\- Scope

\- Acceptance criteria





\### PROJECT\_STATUS.md



Tracks:



\- Current development phase

\- Completed work

\- Next steps





\## Recommended Workflow



1\. Understand requirements

2\. Create project context documents

3\. Plan implementation

4\. Develop features

5\. Verify changes

6\. Maintain project documentation
